# Sprint 7 Task 7A — technical desktop prototype

The Vite production build now uses `/app/` as its base and React Router basename. FastAPI serves that built directory under `/app/` with SPA history fallback; `/api`, `/docs`, and `/openapi.json` stay separate. `/docs` is a local read-only OpenAPI index because the default Swagger UI HTML requested CDN scripts and styles. The app uses bundled JavaScript, CSS and SVG icons plus local system fonts; there are no external asset requests in the browser check. The desktop launcher only opens a validated HTTPS server origin in pywebview. It starts no backend or database.

Exact local prototype steps from repository root: `cd frontend && npm run build`; start a **disposable** PostgreSQL database and apply `cd backend && .venv/bin/alembic upgrade head`; start FastAPI on localhost HTTPS with `CLINIC_PUBLIC_ORIGIN` equal to its actual HTTPS origin; then open `/app/` or run the launcher as described in [desktop README](../../desktop/README.md). For a self-contained synthetic verification that creates and removes only its own database and temporary TLS certificate, run `python3 frontend/tests/run_browser.py --static-only` after the build. The launcher has no certificate-warning bypass and no credentials in its URL. Do not use its self-signed test certificate on a clinic network.

Known limits: this is source-run prototype only. The built `frontend/dist` directory is ignored by Git and must be built/copied with the backend in 7B. The local `/docs` index lists endpoints and links to `/openapi.json` but is not an interactive Swagger UI. Windows renderer, TLS trust and deployment are unverified. Next task: **7B**.
