# Sprint 2 Task 2B — Arabic patients React slice

Next task: **3A**. The existing uncommitted Task 1B shell and API client were part of the starting tree; this checkpoint includes them because the patients route needs the authenticated shell and CSRF client. The unrelated pre-existing AGENTS.md edit remains uncommitted. No appointment features or backend migrations were added.

The `/patients` route uses real Task 2A APIs through a typed Zod client. It supports an administrative table, name/phone search, ten-record pagination, create and edit forms, details, and archive with confirmation. React Hook Form handles forms, Zod validates input and responses, and TanStack Query invalidates list and detail caches after changes. The UI sends only `full_name`, `phone`, `birth_date` and optional `confirm_duplicate`. It keeps the CSRF token in memory; no credentials or tokens use localStorage. Patient identity shown in tests is synthetic. Arabic `lang=ar dir=rtl` remains in `index.html`; CSS handles mobile and keyboard focus. The auth session, role and CSRF checks remain authoritative in FastAPI; hiding a menu is not a permission boundary.
